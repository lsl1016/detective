# 交叉验证方法论

适用于现场、证词、档案之间出现冲突时。

1. 先列“冲突命题”，不要直接跳到凶手结论。
2. 对每个命题分别列出支持证据和反证据，并保留证据 id。
3. 区分来源类型：现场客观痕迹、证人陈述、系统/档案记录。
4. 优先用独立来源互证，避免用同一证人的不同说法互相证明。
5. 如果冲突不能消解，明确标记“未解决”，不要补造缺失事实。
6. 最终指认必须说明：哪一个矛盾被哪几条独立证据消解。
