# 时间线重建

1. 抽取所有明确时间点和时间区间。
2. 每一条记录都保留来源：证据 id / NPC id / 档案 id。
3. 把“客观记录时间”和“证人自述时间”分开标注。
4. 对无法精确到分钟的内容使用区间，不擅自补齐。
5. 找出同一人物在同一时间段的地点冲突、行为冲突和不可达区间。
6. 输出结论前，先给出按时间排序的表，再说明关键冲突。
