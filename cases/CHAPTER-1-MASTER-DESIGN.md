# 第一章 MASTER：栖鸦恢复网络

## 一句话定义

第一章暗线的真相不是“一个幕后黑手操纵所有杀人案”，而是：**一套在 2008~2012 年档案数字化/系统迁移项目中留下的恢复入口长期没有被彻底回收，陆闻川（L.W.C.）持续掌握这套入口，并在当前时间把恢复能力作为有偿服务重新启用。**

CASE-003/005/008/009 是历史锚点；CASE-011~014 是从历史到当前活动的桥；CASE-015 完成身份、控制权、现代活动和当前犯罪四条链的合并。

## 为什么这样比“陆闻川操纵所有凶手”更合理

旧案 ground truth 已经为陈仲、孟启、宋屿、顾岳等人建立了完整的本地动机和作案链。如果在终章突然宣布他们都受陆闻川指挥，会破坏前面案件的因果自洽，也会让长期记忆评测退化成“记住作者后加的设定”。

现在的 MASTER 设计保持两层事实同时成立：

1. 各单案犯罪是独立成立的；
2. 多家机构共享一条真实存在的历史迁移/恢复服务链，而这条服务链在当前仍被陆闻川主动经营。

这样 MASTER 测的是**跨案实体解析、来源追踪、时间跨度与因果边界控制**，而不是剧情强行反转。

## 机械判分面

### 1. `cross_case_dependencies`

声明：

- 历史来源案件；
- 历史 evidence refs；
- 当前 evidence refs；
- 需要建立的高价值判断；
- 是否为单案/Master 必需。

编译器会验证 source/current refs 全部真实存在。

### 2. `cross_case_quiz`

对 `historical_only: true` 的题，Evaluator 自检同时要求：

- 标准答案或 alias 必须出现在声明的历史 source case 运行材料中；
- 标准答案和 aliases 不得出现在当前 case 运行材料中。

因此这类题不能通过当前 Case Server 重新检索得到。

### 3. `master_truth`

CASE-015 增加：

```yaml
master_truth:
  mastermind: 陆闻川
  network_name: 栖鸦恢复网络
  required_dependency_ids: [...]
  required_terms: [...]
```

`evaluator -mode master` 同时检查：

- mastermind；
- network name；
- 关键结论术语；
- 8 条依赖是否全部被引用。

### 4. Scope Guard

Master 结论必须明确保留下面的边界：

```text
“陆闻川是恢复网络组织者”
          ≠
“陆闻川指挥此前所有单案凶杀”
```

这不是文学上的保守，而是长期记忆评测中的重要指标：**模型是否能记住来源和事实范围，而不是把相关事实错误合并。**
